# Grant Executable Permissions to `xfusioncorp.sh`

In the Stratos Datacenter, the `xFusionCorp Industries` sysadmin team has developed a Bash script named `xfusioncorp.sh` to automate backup processes.

The script has been distributed to all necessary servers but lacks executable permissions on **App Server 3**.

## Task

Grant executable permissions to `/tmp/xfusioncorp.sh` on App Server 3, ensuring that **all users** have the capability to execute it.
